# 🚀 Turnstile Auto

📖 [Read in English](./README_EN.md)

Turnstile Auto เป็นเครื่องมือที่ช่วยให้ Checkbox Turnstile สามารถทำงานอัตโนมัติ ✅ เพื่อลดความยุ่งยากในการยืนยันตัวตน

## 🔥 คุณสมบัติ
- 🔄 ทำงานร่วมกับ Checkbox Turnstile โดยอัตโนมัติ
- 🖥️ ติดตั้งง่ายผ่าน Chrome Extension
- ⚡ ใช้งานได้ทันทีหลังจากติดตั้ง

## 🛠 วิธีการติดตั้ง
1. 📥 ดาวน์โหลดโค้ดจาก repository นี้
2. 🌐 เปิด Google Chrome และไปที่ `chrome://extensions/`
3. 🛠 เปิดโหมด "Developer mode" (โหมดนักพัฒนา)
4. 📂 คลิก "Load unpacked" และเลือกโฟลเดอร์ที่เก็บไฟล์ของ Extension
5. ✅ ติดตั้งเสร็จสิ้น สามารถใช้งานได้เลย

## 🎯 วิธีใช้งาน
หลังจากติดตั้งเสร็จสิ้น ระบบจะทำงานอัตโนมัติเมื่อพบ Checkbox Turnstile บนหน้าเว็บไซต์
