# 🚀 Turnstile Auto

📖 [อ่านเป็นภาษาไทย](./README.md)

Turnstile Auto is a tool that allows Checkbox Turnstile to function automatically ✅, reducing the hassle of identity verification.

## 🔥 Features
- 🔄 Automatically works with Checkbox Turnstile
- 🖥️ Easy installation via Chrome Extension
- ⚡ Ready to use immediately after installation

## 🛠 Installation Guide
1. 📥 Download the code from this repository
2. 🌐 Open Google Chrome and go to `chrome://extensions/`
3. 🛠 Enable "Developer mode"
4. 📂 Click "Load unpacked" and select the folder containing the extension files
5. ✅ Installation complete! Ready to use

## 🎯 How to Use
Once installed, the system will automatically work whenever it detects a Checkbox Turnstile on a website.
